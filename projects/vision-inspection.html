Automated Vision Inspection System

A multi-feature inspection station built from scratch — sensing stack, fixture, control panel and relay logic — that cut inspection cycle time from 83 seconds to 47.

RoleDesign & build lead
DisciplinesMechanical, controls, sensing
Cycle time83s → 47s (−43%)
StatusDeployed in production

The problem

Part inspection was manual and serial: an operator checked several features one at a time, which made the station both the slowest step and the least repeatable one. Inspection quality varied by operator and by shift, and the 83-second cycle set the ceiling for the whole line.

The goal was to check every feature in a single automated pass, with a result the line could trust without a second look.

Approach

Sensing stack. No single sensor covered every feature, so I combined three: machine vision for presence and geometry checks, proximity sensing for seating and part-present confirmation, and laser measurement for dimensional features where vision alone was not repeatable enough. Each feature was assigned to the sensor with the best signal-to-noise for that geometry rather than forcing one modality across the part.

Fixture. The fixture had to locate the part repeatably enough that fixed-position sensors stayed valid part to part — otherwise every sensor needs its own search routine and the cycle time goes back up. I designed it around hard datums with positive part seating, so load position is deterministic and sensor windows can be tight.

Controls. The station runs on relay-based logic with a purpose-built control panel. Relay logic was the right call here: the sequence is deterministic, the I/O count is modest, and the maintenance team on the floor can troubleshoot it without a laptop and a software license.

Parallelism. Most of the 43% cycle reduction came from checking features concurrently rather than serially, which the fixed-sensor layout made possible.
